# Deque

## Abstract Data Type

```
trait Deque<T> {
    fn front(&self) -> E;
    fn back(&self) -> E;
    fn push_front(&mut self, element: E);
    fn push_back(&mut self, element: E);
    fn pop_front(&mut self) -> E;
    fn pop_back(&mut self) -> E;
}
```
