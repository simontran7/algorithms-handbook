# Deque

## Abstract Data Type

```
trait Deque<T> {
    fn new() -> Self;
    fn front(&self) -> T;
    fn back(&self) -> T;
    fn push_front(&mut self, item: T);
    fn push_back(&mut self, item: T);
    fn pop_front(&mut self) -> T;
    fn pop_back(&mut self) -> T;
}
```
